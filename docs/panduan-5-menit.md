# Panduan 5 Menit EcoSpend

1. **Buka mode demo** di `/dashboard?demo=1` tanpa akun: lihat ringkasan, grafik arus kas, dan distribusi kategori.
2. **Tambah transaksi** via tombol Tambah transaksi; coba filter, sortir, dan ekspor CSV.
3. **Buat anggaran** per kategori; lihat progres dan proyeksi akhir bulan.
4. **Cek Jejak Karbon**: total estimasi, sumber kategori, tingkat keyakinan, dan disclaimer metodologi.
5. **Daftar akun** bila ingin data sendiri: register → konfirmasi email → onboarding (nama, mata uang, target tabungan) → catat transaksi pertama.
6. **Impor data lama** via halaman Impor: unduh template CSV, isi, lalu ikuti mapping → preview → validasi → konfirmasi.

Tips: mulai dari satu akun dan tiga kategori; tambah aturan merchant agar kategorisasi otomatis makin akurat; ekspor JSON berkala sebagai arsip pribadi.
